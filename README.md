# Overview

ArtistHood is a **Full-Stack MERN** platform built to empower artists with a dedicated digital space where they can showcase their creativity, establish a professional online presence, connect with other creators, and discover new opportunities.

The application combines a modern React frontend with a scalable Node.js & Express backend and MongoDB database to deliver a responsive and extensible experience.

# Getting Started

### Clone the repository

```bash
git clone https://github.com/pasiabhishek/ArtistHood.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm run dev
```

### Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
