# 🎨 ArtistHood

### Discover • Showcase • Hire Creative Talent

**ArtistHood** is a full-stack MERN platform that connects artists with clients through a seamless booking experience. Artists can showcase their portfolios, build their professional presence, and get discovered, while clients can explore talent, compare portfolios, and hire the right creative professional for their projects.

## Overview

Finding the right artist for a project often means searching across multiple social media platforms, messaging apps, and portfolio websites. ArtistHood brings everything together in one place.

The platform enables artists to create professional profiles, showcase their work, and reach potential clients. At the same time, clients can browse portfolios, discover talented creators, and connect with artists for collaborations, freelance work, or bookings.

Built using the **MERN Stack**, ArtistHood is designed with scalability, performance, and user experience in mind.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/pasiabhishek/ArtistHood.git
```

### Install Frontend Dependencies

```bash
cd frontend
npm install
npm run dev
```

### Install Backend Dependencies

```bash
cd backend
npm install
npm run dev
```

### Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
