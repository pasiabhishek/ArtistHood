## 📌 Overview

**ArtistHood** is a creative networking platform where artists can build their digital presence, showcase their work, and connect with a community of creators.

Whether you're a **painter, photographer, designer, musician, writer, filmmaker, or digital artist**, ArtistHood provides a space to express your creativity and gain visibility.

The project emphasizes clean design, seamless navigation, and a responsive experience while laying the foundation for a complete artist-focused social platform.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/pasiabhishek/ArtistHood.git
```

### Navigate to the project

```bash
cd ArtistHood/FrontEnd
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
